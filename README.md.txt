## ✨ About This Project

This learning journey spanned approximately **four months**.  
It began with foundational courses at **Birzeit University**, then evolved into deeper mastery through a structured online program offered by **the University of Michigan** on **Coursera**.

🧠 The specialization contains four courses. The first two were completed:

- ✅ [Programming for Everybody (Getting Started with C)](https://www.coursera.org/specializations/c-programming)
- ✅ [Advanced Programming in C](https://www.coursera.org/specializations/c-programming)

This repository documents the practical exercises developed throughout the learning process, aiming to reinforce concepts and help others learning the C language.

---

## 📂 Folder Structure

- **C-Basic-Programs/** – Foundational C practice problems categorized by topic:
  - `arrays/` – Array manipulation (sum, reverse, multiply)
  - `conditions/` – Programs using `if`, `else`, `switch`
  - `file-handling/` – File I/O operations (`fopen`, `fprintf`, etc.)
  - `functions/` – User-defined functions and recursion
  - `pointers/` – Pointer arithmetic and usage
  - `strings/` – String manipulation, `strtok`, comparisons
  - `structs/` – Using `struct` to model and process data
  - `basic/` – Simple C programs (loops, input/output, arithmetic)

- **projects/** – Larger or more integrated C programs (e.g. bookstore system)
- **certificates/** – Contains earned certificates from online courses
