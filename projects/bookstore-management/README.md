# 📚 Bookstore Management System

A simple C program to manage a bookstore using arrays and file handling.

## Features

- Add a book
- Remove a book
- Search by bin number
- Display all books
- Save updates to a file

## Usage

The program reads from and writes to a file named `books.txt`.

```bash
gcc main.c -o bookstore
./bookstore
```
